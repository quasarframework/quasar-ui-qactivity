## What is QActivity

QActivity is a small Quasar component package for building activity lists and timelines. It provides a wrapper component, `QActivity`, and item rows, `QActivityItem`, that can show icons, avatars, media, Quasar components, or custom slot content.

Use it for audit trails, notification streams, release notes, customer activity, order history, or any place where ordered events should read clearly.

## Components

- `QActivity` provides the list container and vertical timeline bar.
- `QActivityItem` provides each timeline row, marker, and content slot.
